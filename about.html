Features

Everything you need to make a bitmap font

Draw glyphs pixel by pixel, tune metrics with draggable guides, preview text in real time.

✏️

Pixel Grid Editor

Click or drag to set pixels. Draw, fill, shift, flip, undo — full editing toolkit with keyboard shortcuts.

📐

Live Metric Guides

Drag ascender, cap-height, x-height, baseline, and descender lines directly on the canvas.

🔤

Full Character Set

Navigate 191 glyphs — uppercase, lowercase, digits, and punctuation — with a scrollable glyph panel.

👁️

Real-time Preview

Type sample text and see it render at any scale using your font as you design it.

📚

Font Library

Save your fonts locally and browse open-source bitmap fonts as starting points — all free to use and modify.

📦

Export Anywhere

Export as a working TTF vector font, BDF bitmap file, or Glyphon's portable JSON format.
